# 극장 기록 허브 UI

## 현재 시안

- `preview.png`: 메인 메뉴의 `THEATRE RECORDS`에서 진입하는 기록 허브, 1920×1080.
- `preview-script-library.png`: 한 번 상연한 대본과 다음 공연 보상 풀의 자동 `×2.2` 가중치를 확인하는 대본 서고, 1920×1080.
- `preview-script-library-v2.png`: 카드형 격자 대신 얇은 대본 묶음을 세 단 문서함에 축적해 서고 느낌을 강화한 비교 시안, 1920×1080.
- `preview-relic-storage-final.png`: 최대 2개의 128px 공용 유물 소켓, 선택 상세와 작은 적용 버튼을 하나의 얕은 보관 서랍 프레임에 합친 기준안, 1920×1080.
- `preview-performance-history.png`: 전체 공연·승리·구출 3개 요약, 최근 공연 5행과 선택 공연의 핵심 결과만 보여주는 공연 이력 화면, 1920×1080.
- 상세 데이터를 한 화면에 펼치지 않고 네 기록 화면으로 들어가는 입구만 표시한다.
- 각 행의 숫자는 진행 상황을 빠르게 확인하기 위한 보조 정보이며 런타임 데이터로 교체한다.

## 메뉴 구조

1. `COMPENDIUM`: 릴·대본·유물·무대·감독·적의 계정 공유 읽기 전용 도감.
2. `SCRIPT LIBRARY`: 상연한 대본, 해금 여부와 다음 런 등장 가중치를 관리하는 서고.
3. `RELIC STORAGE`: 이전 공연에서 남긴 계승 유물을 확인하고 다음 공연의 시작 유물을 고르는 창고.
4. `PERFORMANCE HISTORY`: 공연 횟수, 승리, 최고 기록, 영혼 구조와 세부 통계를 확인하는 기록부.

`COMPENDIUM`의 대본·유물 탭은 발견 기록을 읽는 곳이고, `SCRIPT LIBRARY`와 `RELIC STORAGE`는 다음 공연에 영향을 주는 실제 보유·선택 화면이다.

## 구현 메모

- 정적 기록실 배경과 공용 메뉴 행 하나를 사용한다.
- 메뉴 행은 아이콘, 제목, 한 줄 설명, 우측 진행 수치만 데이터로 교체한다.
- 선택은 얇은 금색 인셋 테두리와 아이콘 명도만 변경한다.
- 카메라 이동, 서랍 개폐, 책 꺼내기, 파티클과 동적 조명은 사용하지 않는다.

## Figma 최종 조립

- 전체 UI 1차 시안 완료 후 Figma Design에 모든 1920×1080 화면을 프레임으로 배치한다.
- `00 FLOW MAP`, `01 FULL SCREENS`, `02 COMPONENTS`, `03 PROTOTYPE` 네 페이지를 기본으로 사용한다.
- `FLOW MAP`에는 화면 이미지를 축소 배치하고 이미지 속 버튼과 이동 대상을 화살표로 연결한다.
- `PROTOTYPE`에는 이미지 위 투명 핫스팟을 얹어 `Navigate to`, `Open overlay`, `Back` 동작을 연결한다.
- 버튼 컴포넌트는 기본·호버·선택·비활성 상태를 variant로 만들고 실제 에셋 분리는 후속 작업으로 진행한다.
