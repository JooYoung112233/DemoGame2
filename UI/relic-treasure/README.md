# 유물 보물 3택 1 UI

## 현재 시안

- `preview.png`: 극장 유실물 보관함에서 유물 하나를 고르는 화면, 1920×1080.
- `preview-v2.png`: 서랍 원근과 실물 깊이를 제거한 정면 2D 유실물 보관판 기준안, 1920×1080.
- 일반 공연 보상, 오디션, 상점과 구분하기 위해 열린 단일 서랍과 세 개의 실물 유물만 사용한다.
- 시안의 개막 북, 감독의 돋보기, 앙코르 종은 현재 `tools/engine.js`의 실제 유물 데이터다.

## 화면 구조

- 어두운 배경 위에 원근이 없는 정면 벨벳 보관판 하나를 중앙에 둔다.
- 얇은 세로선 두 개로 같은 폭의 세 칸을 만들고 각각 유물, 이름, 한 줄 효과, 현재 보유 중첩만 표시한다.
- 가격, 등급 설명, 긴 플레이버 텍스트, 인벤토리 비교는 표시하지 않는다.
- 처음 얻는 유물은 `NEW`, 보유 유물은 `OWNED N / 3`으로 표시한다.
- 현재 2개를 가진 유물은 선택 시 `NEXT: COMPLETE` 표식을 함께 보여준다.
- 같은 유물은 중첩 가능하며 선택지 안에서는 같은 유물이 중복 등장하지 않는다.
- `TAKE THIS RELIC`로 확정하고 `LEAVE IT`으로 포기한다.

## 완성 표시

- `DESIGN.md`에는 같은 유물 3개 획득 시 완성 보너스가 있다고 기록되어 있다.
- 개별 완성 보너스 효과는 현재 엔진 데이터에 없으므로 이번 시안에서는 완성 임박 상태만 준비한다.
- 실제 효과가 확정되면 상세 툴팁에서 보여주고 선택 화면에는 `NEXT: COMPLETE`만 유지한다.

## 구현 메모

- 배경은 평면 검정 오버레이, 보관판은 정면 공용 패널 하나로 구성한다.
- 유물 세 개는 동일한 시각 경계 안에 들어가는 정면 2D 아이콘 스프라이트로 제작한다.
- 원근, 접지면, 입체 서랍, 손잡이, 실물형 재질과 반사광을 사용하지 않는다.
- 라벨은 별도 종이판 없이 보관판 위 런타임 텍스트와 얇은 구분선으로 구성한다.
- 선택은 얇은 인셋 테두리, 작은 체크 표식, 소품 밝기 변화만 사용한다.
- 선택 상태에서 투사광이나 새 그림자를 만들지 않는다. 접지 그림자는 모든 상태에 동일하게 구운다.
- 연기, 파티클, 반사광, 움직이는 서랍 애니메이션은 첫 구현에서 사용하지 않는다.
