# 막 전환 UI

## 현재 시안

- `preview.png`: 1막 종료 뒤 2막 진입을 알리는 완전 폐막 상태의 검토용 화면, 1920×1080.
- 보상이나 선택 화면이 아니라 자동으로 지나가는 짧은 전환이다.
- 중앙에는 다음 막 번호와 제목만 크게 표시하고, 3막 진행 표시는 작은 보조 정보로 둔다.

## 화면 흐름

1. 전투 UI와 적을 숨기고 기존 좌우 커튼을 `0.55초` 동안 닫는다.
2. 커튼이 맞물린 뒤 막 제목과 진행 표시를 `opacity`로 한 번 나타낸다.
3. 완전 폐막 상태를 약 `0.9초` 유지하는 동안 다음 막의 지도와 배경을 준비한다.
4. 제목을 먼저 지우고 기존 커튼을 `0.60초` 동안 열어 다음 막으로 전환한다.

전체 전환은 약 `2.1초`이며 입력 없이 자동 진행한다. 로딩이 길어질 때만 완전 폐막 프레임을 유지한다.

## 막별 문구

| 진입 | 막 제목 |
|---|---|
| 1막 | `ACT I` / `THE ABANDONED AUDITORIUM` |
| 2막 | `ACT II` / `THE KING'S TRAGEDY` |
| 3막 | `ACT III` / `THE FIRST NIGHT` |

문구는 이미지에 굽지 않고 런타임 텍스트로 교체한다.

## 구현 메모

- `UI/theater`의 열린·닫힌 좌우 커튼과 상단 발란스를 그대로 재사용한다.
- 막 제목, 가면 문장, 가는 장식선, 3단 진행 표시만 별도 UI 레이어로 둔다.
- 커튼 마스크 이동, 텍스트 알파, 새 배경 교체만 사용한다.
- 스포트라이트 콘, 파티클, 연기, 천 물리, 3D 카메라 이동은 사용하지 않는다.
- 전환 중에는 클릭과 키 입력을 잠그고, 커튼이 완전히 닫힌 순간에만 다음 막 데이터를 적용한다.
