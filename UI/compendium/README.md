# 극장 도감 UI 1차 시안

`preview.png`은 계정 전체에서 발견한 릴·대본·유물·무대·감독·적을 찾아보는 1920×1080 기록 화면이다. 구매, 강화, 영구 기능 해금은 하지 않는다.

## 카테고리

현재 구현 데이터의 전체 수량을 기준으로 한다.

| 탭 | 전체 수량 | 기록 조건 |
|---|---:|---|
| 릴 | 26 | 해당 심볼을 한 번 획득하거나 사용 |
| 대본 | 97 | 해당 대본을 한 번 상연 |
| 유물 | 27 | 해당 유물을 한 번 획득 |
| 무대 | 8 | 일반 무대 6종 또는 에픽 무대 2종을 한 번 완성 |
| 감독 | 8 | 해당 감독을 해금 |
| 적 | 15 | 해당 적과 한 번 조우 |

- 검열용 내부 카드와 보석은 릴 도감 진행률에서 제외한다.
- 도감은 난이도 세이브와 분리된 계정 공유 데이터다.
- 탭의 `발견 / 전체` 수치는 데이터에서 계산하며 이미지의 발견 수치는 예시다.

## 화면 구조

- 상단에는 뒤로 가기, `극장 기록`, 계정 공유 표기, 6개 카테고리 탭, 필터·검색을 둔다.
- 왼쪽은 선택 카테고리의 썸네일 목록이다. 무대 8종은 스크롤 없이 전부 보인다.
- 오른쪽은 선택한 항목 하나의 큰 삽화와 조건·효과·최초 발견 기록을 보여준다.
- 시안은 `무대` 탭과 `거울의 무대` 상세를 예시로 한다.

## 발견 상태

- `발견`: 이름, 삽화, 조건, 효과, 최초 기록을 모두 표시한다.
- `새 항목`: 발견 항목에만 작은 `NEW` 리본을 붙이고 처음 열람하면 제거한다.
- `미발견`: 어두운 실루엣과 `미발견`만 표시한다. 정확한 이름·조건·효과는 숨긴다.
- 무대는 한 번 완성한 뒤부터 조건 전체를 공개한다. 미발견 무대에는 `무대를 한 번 완성하면 조건이 기록됩니다`만 표시한다.

## 무대 상세

- 섹션 제목은 복원 목록과 혼동하지 않도록 `STAGE CONDITIONS`를 사용한다.
- 일반 무대 조건은 릴·유물·대본 세 소켓의 현재 요구량을 표시한다.
- 완성 효과와 보조 수치는 별도 구역으로 분리한다.
- 최초 완성 난이도·층과 누적 완성 횟수는 작은 기록 행으로 둔다.
- 에픽 무대는 같은 레이아웃에서 조건 소켓의 종류와 개수만 교체한다.

## 런타임 제작 기준

- 정적 서고 배경, 카테고리 탭, 썸네일 공용 타일, 미발견 덮개, `NEW` 리본, 상세 종이, 조건 소켓, 기록 행으로 분리한다.
- 카테고리 변경은 내용 교체만 사용하며 책 넘김이나 카메라 이동은 넣지 않는다.
- 호버는 외곽선과 4px 이동, 선택은 금색 외곽선으로 구분한다.
- 검색은 이름, 효과 키워드, 요구 심볼을 대상으로 하고 작은 공용 오버레이 입력창을 연다.
- 파티클, 3D 책, 긴 페이지 전환, 구매 버튼은 사용하지 않는다.
