# 극단 성장 3택 1 UI

## 현재 시안

- `preview.png`: 막 보스 이후 또는 비극 보상에서 사용하는 극단 성장 선택 화면, 1920×1080.
- `preview-v2.png`: 현재 극단 요약을 상단으로 옮기고 단계 표시를 명시적인 수치·분할 막대로 교체한 기준안, 1920×1080.
- `preview-v3.png`: 하단 단계 영역을 제거하고 각 선택지 좌상단의 작은 `LV` 점으로 축약한 기준안, 1920×1080.
- `preview-v4.png`: 효과와 적용 전후 수치를 한 줄에 합치고 선택판 높이를 줄인 확정 기준안, 1920×1080.
- 일반 보상 카드가 아니라 극단의 배역 공고판 한 장에서 세 가지 운영 변경 중 하나를 고른다.
- 시안은 현재 데이터와 충돌이 없는 `개막 예산`, `대본 창고`, `이중 캐스팅`을 예제로 사용한다.

## 화면 구조

- 기존 무대 배경 위에 단순 검정 오버레이를 씌우고 중앙에 정면 공고판을 연다.
- 세 선택지는 별도 카드가 아니라 공고판 내부의 같은 폭 세 열이다.
- 공고판 제목 바로 아래에 현재 극단의 주요 수치를 큰 가로 요약줄로 표시한다.
- 각 열에는 2D 아이콘, 이름, 한 줄 효과를 표시하며 적용 전후 수치는 효과 오른쪽의 작은 배지에 넣는다.
- 적용 전후 수치를 위한 별도 하단 구획이나 큰 숫자 행은 만들지 않는다.
- 성장 단계는 각 열의 좌상단에 작은 `LV` 점으로 표시한다. 점 개수가 최대 단계이며 보유 단계는 금색, 이번 선택으로 추가되는 단계는 적금색, 미획득 단계는 어두운 내부와 금색 윤곽을 사용한다.
- 선택 시 얇은 인셋 테두리, 체크 표식, 아이콘 틴트만 변경한다.
- 필수 선택이므로 취소·건너뛰기 버튼은 두지 않는다.
- 단계 점은 12~14px 수준의 작은 상태 표시이며 버튼 프레임, 그림자, 호버를 사용하지 않는다.

## 기획 충돌 메모

- `tools/engine.js`에는 `무대 확장`이 남아 있지만 `DESIGN.md` 61.3에서는 슬롯 4칸을 메타 복원으로 옮기며 극단 성장에서 제거했다고 기록되어 있다.
- 실제 UI 데이터 연결 전 `stage` 선택지를 유지할지 제거할지 확정해야 한다.
- 시안에는 이 충돌을 피하기 위해 `stage`를 넣지 않았다.

## 구현 메모

- 어두워진 기존 무대 배경, 정면 공고판, 세로 구분선 두 개를 공용으로 사용한다.
- 선택지 아이콘과 텍스트만 데이터로 교체한다.
- 단계 표시는 공용 소형 점으로 만들며 이미 최대인 항목은 후보 풀에서 제외한다.
- 증가 전후 숫자는 현재 런 상태와 선택 효과에서 런타임으로 계산한다.
- 선택 상태에서 동적 라이트, 투사광, 그림자 변화, 크기 확대를 사용하지 않는다.
