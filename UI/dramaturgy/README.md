# 각색실 UI 1차 시안

`preview.png`은 각색실의 전체 화면 구조와 실제 플레이 크기를 확인하기 위한 1920×1080 승인본이다.
`preview-disabled-cover-v1.png`은 진화나 강화가 가능한 대상이 없을 때 사용하는 비활성 슬롯 시안이다.

## 화면 역할

- 상점처럼 재화를 지불하는 화면이 아니라, 여정 노드에서 보유 대상을 변화시키는 화면이다.
- 첫 화면에서는 `배역 진화`와 `장면 각색` 두 방식만 고른다.
- 방식을 누르면 별도의 보유 대상 선택 오버레이를 연다. 첫 화면에 전체 릴이나 대본 목록을 펼치지 않는다.

## 기능 구분

- 배역 진화: 동일 배역 3개를 진화 배역 1개로 바꾼다.
- 장면 각색: 보유 대본의 효과 수치를 강화하며, 상점의 비용 감소형 `대본 승급`과 역할을 분리한다.
- 합성: 규칙과 구현 범위가 확정되지 않아 이번 시안에서는 잠금 칸도 만들지 않고 완전히 제외한다.

## 런타임 제작 기준

- 패널, 아이콘 소켓, 화살표, 수치 영역을 재사용 가능한 정적 스프라이트로 구성한다.
- 상호작용은 외곽선, 색상, 소폭 위치 이동만 사용한다.
- 동적 조명, 파티클, 종이 변형, 깃펜 필기 애니메이션은 사용하지 않는다.
- 실제 배역·대본 이미지와 수치는 데이터 바인딩 시 교체한다.
- 사용 가능한 대상이 없으면 내부 요소를 각각 흐리게 만들지 않고, 슬롯 전체를 불투명한 극장식 덮개 스프라이트 하나로 가린다.
- 비활성 덮개에는 중앙 문양과 짧은 사유만 표시한다. 덮개는 런타임에서 단순 활성/비활성하며 필요하면 수직 슬라이드 또는 회전 열림만 추가한다.
