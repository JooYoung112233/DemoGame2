# 전체 게임 UI 화면 로드맵

`DESIGN.md`의 현재 규칙을 기준으로 한 전체 게임 UI 제작 목록이다. 전투뿐 아니라 게임 실행, 런 준비, 3막 여정, 보상, 메타 성장, 재연과 도감을 모두 포함한다.

## 진행 상태

- `[ ]` 미착수
- `[~]` 1차 제작 또는 임시 확정
- `[x]` 최종 확정 및 런타임 레이어 분리 완료

## 1차 제작 순서

| 번호 | 상태 | 화면 | 1차 검증 목표 |
|---:|:---:|---|---|
| 1 | `[~]` | 여정 지도 | 3막×12층, 2~3갈래 노드, 현재 위치와 다음 선택의 가독성 |
| 2 | `[ ]` | 공연 보상 | 배역 3개와 대본 3개를 함께 보여주고 하나를 고르는 구조 |
| 3 | `[ ]` | 소품실·상점 | 배역·대본·유물 구매/판매와 현재 릴 비교 |
| 4 | `[ ]` | 각색실 | 배역 진화, 대본 강화, 합성의 구분 |
| 5 | `[ ]` | 사건·즉흥극 | 이야기, 대가, 결과가 명확한 선택지 구성 |
| 6 | `[ ]` | 분장실 | 회복과 준비 선택을 짧고 명확하게 표현 |
| 7 | `[ ]` | 감독 선택 | 감독 8명, 고유 능력, 유품, 해금 상태 |
| 8 | `[ ]` | 매표소·공연 준비 | 난이도, 시작 릴·대본, 계승 유물을 한 흐름으로 구성 |
| 9 | `[ ]` | 패배·승리 정산 | 도달 층, 조각, 발견, 해금, 계승 결과 |
| 10 | `[ ]` | 복원 목록 | 대본 조각과 가지형 영구 해금 구조 |
| 11 | `[ ]` | 도감 | 배역, 대본, 유물, 무대, 감독, 적 카테고리 |
| 12 | `[ ]` | 재연·이력·퀘스트 | 재연 1~8단, 영구 퍽 3택1, 실패 보상 퀘스트 |

## 함께 필요한 보조 화면

아래는 위 주요 화면을 만들면서 필요한 시점에 붙인다.

| 구분 | 화면·패널 |
|---|---|
| 시작 | 타이틀, 새 공연, 이어하기, 난이도별 세이브 선택 |
| 여정 | 오디션 3택1, 유물 보물 3택1, 극단 성장, 막 전환 |
| 전투 | 대본 상세, 적 인텐트, 유물 툴팁, 관객의 요구, 무대 진행도, 커튼콜, 유품 사용 확인 |
| 메타 | 극장 창고, 대본 서고, 극장 기록·통계 |
| 시스템 | 일시정지, 설정, 확인 팝업, 저장 버전 불일치 안내 |
| 이야기 | 매표소 도입, 영혼 구출, 초대 감독, 마지막 장면과 엔딩 |

## 공통 제작 원칙

- 기준 화면은 1920×1080, 16:9다.
- 1차 시안은 전체 화면에서 실제 표시 크기로 검증하며 개별 장식부터 만들지 않는다.
- 기존에 확정된 전투 UI, 극장 무대, 커튼, 관객, 슬롯, 대본, HP·코스트 에셋을 우선 재사용한다.
- 숫자, 설명, 잠금 상태와 선택 결과는 이미지에 굽지 않고 런타임 UI로 분리한다.
- 컨펌 전에는 레이어를 세부 분리하지 않는다.
- 임시 확정된 화면의 미세 조정은 전체 1차 제작 완료 후 공통 스타일과 함께 처리한다.
- 사용자가 `확인`이라고 하면 그때 확정된 작업 범위만 정리해 커밋하고 푸시한다.

## 후속 다듬기 목록

화면을 빠르게 넘길 때 보류한 글자 크기, 여백, 애니메이션, 버튼 상태, 레이어 분리 항목을 여기에 누적한다.

- 여정 지도 1차안: 노드 아이콘은 최종 단계에서 종류별 공용 아이콘 세트로 통일하고, 잠금·도달·선택 상태를 분리한다.
- 여정 지도 1차안: 컨펌 후 배경판, 경로선, 노드 베이스, 단순 발광 오버레이를 런타임 레이어로 분리한다.
