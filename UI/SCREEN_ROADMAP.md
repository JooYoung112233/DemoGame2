# 전체 게임 UI 화면 로드맵

`DESIGN.md`의 현재 규칙을 기준으로 한 전체 게임 UI 제작 목록이다. 전투뿐 아니라 게임 실행, 런 준비, 3막 여정, 보상, 메타 성장, 재연과 도감을 모두 포함한다.

## 진행 상태

- `[ ]` 미착수
- `[~]` 1차 제작 또는 임시 확정
- `[x]` 최종 확정 및 런타임 레이어 분리 완료

| 번호 | 상태 | 화면 | 1차 검증 목표 |
|---:|:---:|---|---|
| 1 | `[~]` | 여정 지도 | 3막×12층, 2~3갈래 노드, 현재 위치와 다음 선택의 가독성 |
| 2 | `[~]` | 공연 보상 | 배역 3개와 대본 3개를 함께 보여주고 하나를 고르는 구조 |
| 3 | `[~]` | 소품실·상점 | 배역·대본·유물 구매/판매와 현재 릴 비교 |
| 4 | `[~]` | 각색실 | 배역 진화와 장면 각색을 먼저 선택하고 보유 대상을 고르는 2단계 구조 |
| 5 | `[~]` | 사건·즉흥극 | 왼쪽 사건 삽화와 이야기, 오른쪽 `대가 → 결과` 세로 선택지 구성 |

| 7 | `[~]` | 감독 선택 | 기존 감독 8종 썸네일과 선택 캐릭터 확대, 고유 능력·유품·해금 상태 표시 |
| 8 | `[~]` | 매표소·공연 준비 | 난이도별 세이브 티켓, 시작 릴·대본, 계승 유물, 최종 요약을 한 화면에 구성 |

| 11 | `[~]` | 도감 | 릴, 대본, 유물, 무대, 감독, 적 카테고리 |

## 공통 제작 원칙

- 기준 화면은 1920×1080, 16:9다.
- 1차 시안은 전체 화면에서 실제 표시 크기로 검증하며 개별 장식부터 만들지 않는다.
- 기존에 확정된 전투 UI, 극장 무대, 커튼, 관객, 슬롯, 대본, HP·코스트 에셋을 우선 재사용한다.
- 숫자, 설명, 잠금 상태와 선택 결과는 이미지에 굽지 않고 런타임 UI로 분리한다.
- 컨펌 전에는 레이어를 세부 분리하지 않는다.
- 임시 확정된 화면의 미세 조정은 전체 1차 제작 완료 후 공통 스타일과 함께 처리한다.
- 사용자가 `확인`이라고 하면 그때 확정된 작업 범위만 정리해 커밋하고 푸시한다.

## 후속 다듬기 목록

화면을 빠르게 넘길 때 보류한 글자 크기, 여백, 애니메이션, 버튼 상태, 레이어 분리 항목을 여기에 누적한다.

- 여정 지도 1차안: 노드 아이콘은 최종 단계에서 종류별 공용 아이콘 세트로 통일하고, 잠금·도달·선택 상태를 분리한다.
- 여정 지도 1차안: 컨펌 후 배경판, 경로선, 노드 베이스, 단순 발광 오버레이를 런타임 레이어로 분리한다.
- 공연 보상 1차안: 자리 확인용 배역·대본 이미지를 기존 슬롯 심볼과 대본 런타임 에셋으로 교체한다.
- 공연 보상 1차안: 보상 확률, 보유 수량, 선택 외곽선과 위치 이동은 런타임 UI로 처리한다.
- 공연 보상 1차안: 전체 화면 전환이 아니라 기존 전투 화면 위 중앙 모달로 구현한다.
- 소품실 1차안: 현재 릴 전체를 상시 나열하지 않고 `내 극단` 버튼으로 별도 오버레이를 연다.
- 소품실 1차안: 해금된 배역 3·대본 3·유물 2만 고정 진열하고, 잠긴 상품은 표시하지 않는다.
- 소품실 1차안: 실제 가격, 상품 에셋, 툴팁 내용은 런타임 데이터로 교체한다.
- 각색실 1차안: 배역 진화와 장면 각색만 노출하고, 규칙이 미정인 합성은 잠금 칸 없이 제외한다.
- 각색실 1차안: 방식 선택 뒤 별도의 보유 대상 선택 오버레이를 열고 변경 전·후를 확인한다.
- 사건·즉흥극 1차안: 선택지마다 대가와 예상 결과를 아이콘·숫자로 직접 표시하고, 이탈 선택지를 같은 위치에 둔다.
- 사건·즉흥극 1차안: 호버와 선택을 분리하고, 실제 선택 후에만 하단 확정 버튼을 활성화한다.
- 분장실 1차안: 전체 화면 모달 대신 정적 분장대 배경 위 하단 중앙에 작은 2칸 선택 트레이를 배치한다.
- 분장실 1차안: 회복량·결과 HP와 최대 HP 변경 전·후를 런타임 수치로 직접 비교한다.
- 감독 선택 1차안: 기존 캐릭터 원본 8종을 재사용하고, 선택 감독만 크게 표시하며 하단 썸네일에서 전환한다.
- 감독 선택 1차안: 오른쪽 정보 패널은 고유 능력·유품·기본 수치만 표시하고 시작 구성은 다음 준비 화면으로 넘긴다.
- 매표소·공연 준비 1차안: 난이도별 독립 세이브 경고를 티켓 선택 영역 아래에 고정하고 나중에 변경할 수 없음을 명시한다.
- 매표소·공연 준비 1차안: 시작 릴·대본·계승 유물은 요약만 표시하고 각각 작은 공용 피커에서 교체한다.
- 패배·승리 정산 1차안: 3열 정산판은 폐기하고, 승리는 열린 커튼과 구출된 영혼, 패배는 닫히는 커튼과 멀어지는 영혼을 화면의 중심으로 삼는다.
- 패배·승리 정산 1차안: 핵심 성과와 조각만 하단에 요약하고 계산·발견·해금은 `공연 기록 보기` 공용 오버레이로 내린다.
- 복원 목록 1차안: 대본 조각으로 한 번씩 극장 기능을 복원하며, 극장 배경 속 실제 물품 9종을 직접 눌러 선택하고 작은 공용 팻말에서 효과·비용·잔액을 확인한다.
- 복원 목록 1차안: 선행선은 3개만 사용하고 완료·구매 가능·조각 부족·선행 잠금 상태를 색상과 공용 표식으로 구분한다.
- 도감 1차안: 계정 공유 기록으로 릴·대본·유물·무대·감독·적 6개 탭을 두고, 왼쪽 썸네일 목록과 오른쪽 선택 상세를 공용 구조로 사용한다.
- 도감 1차안: 미발견 항목은 이름·조건·효과를 숨기고, 새 항목은 한 번 열람할 때까지 작은 `NEW` 리본만 표시한다.
- 재연 1차안: 단계가 오를수록 특수 관객이 늘어나는 구성으로 누적 난이도를 표현하고, 각 해금 단계 아래에 누적 시도 횟수를 표시한다.
- 재연 1차안: 현재 1~8단계를 기준으로 하되 8을 UI 상한으로 고정하지 않는다. 8개 초과 시 페이지 또는 수평 스크롤로 확장한다.
- 막 전환 1차안: 기존 좌우 커튼을 완전히 닫은 뒤 다음 막 제목과 작은 3막 진행 표시만 노출하고 자동으로 다시 연다.
- 막 전환 1차안: 약 2.1초 동안 커튼 마스크 이동과 텍스트 알파만 사용하며, 완전 폐막 프레임에서 다음 막 데이터를 교체한다.
- 전투 정보 패널 1차안: 손패에서 선택한 대본을 약간 들어 올리고, 주변 빈 공간에 약 330×175px 축약 상세 패널을 연결한다.
- 전투 정보 패널 1차안: 대본·적 인텐트·유물·관객 요구·무대 진행도·커튼콜은 같은 패널 프레임에서 아이콘과 짧은 데이터 블록만 교체한다.
- 전투 정보 패널 1차안: 대본에 이미 표시된 코스트·요구 심볼은 반복하지 않고 결과 수치와 대상만 보충한다. 특수 규칙은 있는 경우에만 한 줄 추가한다.
- 전투 정보 패널 1차안: 일반 대본은 상세 패널을 열지 않고 선택 카드 외곽선과 코스트 발광을 유지하며, 하단 효과 아이콘·숫자는 어두운 외곽선과 약한 발광으로 읽기 쉽게 만든다.
- 극장 기록 1차안: 메인 메뉴에서 도감·대본 서고·계승 유물 창고·공연 통계로 들어가는 단순 4행 허브를 먼저 연다.
- 극장 기록 1차안: 도감의 대본·유물 탭은 읽기 전용 발견 기록이며, 대본 서고와 유물 창고는 다음 공연에 영향을 주는 실제 관리 화면으로 구분한다.
- 시스템 메뉴 1차안: 전투 화면 위 균일한 검정 오버레이와 약 470×530px 중앙 패널만 사용하며 배경 블러는 넣지 않는다.
- 시스템 메뉴 1차안: 일시정지는 복귀·설정·타이틀 복귀·공연 포기만 표시하고, 공연 포기와 초기화는 공용 2버튼 확인 팝업으로 한 번 더 확인한다.

## Figma 최종 조립 계획

- 전체 UI 1차 시안이 완료되면 Figma Design에 `00 FLOW MAP`, `01 FULL SCREENS`, `02 COMPONENTS`, `03 PROTOTYPE` 페이지를 만든다.
- 모든 검토 이미지를 1920×1080 프레임으로 가져오고, 이미지 속 버튼 위치에 투명 핫스팟을 얹어 화면 이동·오버레이·뒤로 가기를 연결한다.
- 전체 흐름 지도는 화면 썸네일과 버튼 기반 연결선을 크게 펼쳐 검토하며, 실제 클릭 검증은 별도 프로토타입 흐름으로 실행한다.
