## 공용 패널 구조

- 일반 대본은 별도 상세 패널을 열지 않는다.
- 선택 시 카드가 약 `55px` 올라오고, 카드 둘레에 `2~3px` 금색 선과 `5~7px` 이내의 약한 발광을 선택 중 계속 유지한다.
- 코스트 표식은 밝은 숫자와 `1~2px` 어두운 외곽선, `7px` 이내의 약한 발광을 선택 중 계속 유지한다.
- 결과 아이콘과 숫자는 밝은 미색 내부, `2px` 어두운 외곽선, `2px` 이내의 약한 금색 발광을 사용한다.
- 선택 대본은 종이 전체 명도도 함께 올려 손패에서 명확히 분리한다. 단, 코스트와 결과값의 외곽선·상시 발광은 별도로 유지한다.
- 특수 규칙이 있는 대본만 아래 축약 툴팁을 조건부로 연다.
- 대본 툴팁 권장 크기: 약 `330×175px`.
- 제목, 아이콘 중심 핵심 결과 수치와 대상만 표시한다.
- 코스트와 요구 심볼은 대본 본체에서 읽으므로 툴팁에 반복하지 않는다.
- 특수 규칙이 있는 대본만 툴팁 높이를 한 줄 늘려 규칙을 추가한다.
- 긴 설명과 계산식은 넣지 않는다.
- 바깥 클릭이나 다른 대본 선택으로 닫으며 닫기 표식과 확인 버튼은 두지 않는다.
- 패널 위치는 대상 주변 네 후보 위치 중 화면과 중요 HUD를 가장 적게 가리는 곳을 선택한다.

## 구현 메모

- 공용 검정 패널, 금색 테두리, 계열색 탭, 연결선 네 요소만 이미지로 사용한다.
- 모든 아이콘, 텍스트, 수치와 위치는 런타임 UI다.
- 선택 강조는 위치 이동, 지속 외곽선, 코스트 아이콘 상시 발광, 결과 아이콘·숫자 외곽선과 틴트, 주변 손패의 약한 명도 감소만 사용한다.
- 카드 전체 발광, 반복 펄스와 네온 효과는 사용하지 않는다.
- 블러, 동적 스포트라이트, 큰 그림자, 발광 번짐, 화면 전체 암전은 사용하지 않는다.
- 터치 환경에서는 호버 대신 첫 탭으로 상세를 열고 두 번째 탭으로 실행한다.

## 기본 접힘 정책

- HP, 코스트, 슬롯, 손패, 환호 게이지처럼 매 턴 판단에 필요한 정보만 상시 표시한다.
- 적 의도, 관객 요구와 환호 단계 효과, 무대 진행도처럼 확인 빈도가 낮은 정보는 기본값에서 접는다.
- 접힌 관객 요구와 무대 계획에는 작은 아이콘과 새 변화가 있을 때의 알림 점만 남긴다.
- 하나를 펼치면 같은 계층의 다른 상세 패널은 닫는다. 바깥 클릭과 `ESC`로 다시 접는다.
- 침입자 등장, 조건 완성처럼 즉시 대응해야 하는 사건은 설정과 무관하게 짧은 자동 경고를 표시한다.

## 적 의도·침입자 예고

- 기본값에서는 적 의도를 숨긴다. 적을 클릭·첫 탭하면 해당 적 하나의 의도만 HP 아래에 표시한다.
- 접근성 설정의 `적 의도 항상 표시`를 켜면 모든 적의 의도를 상시 표시한다. 기본값은 `끔`이다.
- 공용 프레임 하나에 `남은 턴`, `행동 아이콘`, `기본 수치`, `상태 효과 아이콘·수치`만 런타임으로 교체한다.
- 예시: `1턴 후 공격 8`, `2턴 후 방어 10`, `1턴 후 공격 6 + 출혈 2`.
- 대상, 다단 공격과 상세 효과는 의도 UI에 반복하지 않고 마우스오버·첫 탭 시 공용 상세 패널에서 보여준다.
- 침입자는 등장 한 턴 전에 무대 우측 날개에 `NEXT TURN` 경고만 표시한다. 실제 적의 모습과 능력은 등장 전까지 공개하지 않는다.
- 경고는 중앙 무대, 슬롯, 손패를 가리지 않으며 위치 이동이나 반복 애니메이션 없이 아이콘·문구의 짧은 점등만 사용한다.

## 관객 요구·환호 임계점

- 환호 현재값과 게이지만 상시 표시한다. 관객 요구와 단계 효과는 기본값에서 접는다.
- 비극·주연 전투에서는 환호 게이지 옆에 관객 요구 아이콘과 새 요구 알림 점을 표시하고, 클릭·첫 탭 시 한 줄 패널을 펼친다.
- 요구 프레임은 공용으로 두고 요구 아이콘, 현재 진행·목표 수치, `환호 +30`만 런타임 교체한다.
- 실패 벌칙과 긴 조건 문장은 기본 HUD에 표시하지 않는다. 정확한 판정 조건은 마우스오버·첫 탭 상세에서 확인한다.
- 환호 게이지의 고정 임계점은 `40`, `75`, `100`이다. 40과 75는 피해 증가 단계, 100은 기립 박수다.
- 현재 환호가 넘은 단계만 점등하고 이후 단계는 명도를 낮춘다. 효과 수치와 코스트·골드 보상은 호버 상세에서 보여준다.
- 환호 상한이 바뀌는 유물과 재연 단계에서는 같은 게이지 폭 안에서 임계점 위치를 비율로 다시 계산한다.

## 무대 진행도·교체

- 평소에는 우측 작업대의 작은 무대 아이콘 탭만 표시하고, 클릭·첫 탭 시 계획표를 펼친다.
- 계획표에는 대상 무대 썸네일과 이름, 릴·유물·대본의 `현재/필요` 수치만 표시한다.
- 조건을 채운 항목은 소켓을 점등하고 미완성 항목은 마지막 빈 소켓을 남긴다. 효과 설명은 공용 상세 패널로 분리한다.
- 여러 무대의 진행도는 유지하지만 계획표에는 현재 조준 중인 무대 하나만 표시한다. 탭을 다시 누르면 후보 목록을 연다.
- 세 조건이 모두 충족되기 전에는 `SET STAGE`를 잠그고, 완성 시에만 버튼을 활성화한다.
- `SET STAGE`를 누르면 입력을 잠시 막고 `커튼 닫힘 → 후면 배경 교체 → 커튼 열림` 순서로 전환한다. 별도 3D 전환이나 동적 조명은 사용하지 않는다.
- 무대를 교체해도 다른 무대의 누적 진행도는 지우지 않는다. 활성 무대는 항상 하나만 유지한다.

## 커튼콜

- 커튼콜은 상시 게이지나 별도 패널을 만들지 않고 다음 전투 1턴에 돌아온 대본 자체의 상태로 표시한다.
- 1턴 시작 시 손패 위에 `CURTAIN CALL` 안내를 약 1초 표시한 뒤 자동으로 닫는다.
- 돌아온 대본은 손패보다 약 `55px` 올라오며 상단에 붉은 커튼 탭, 코스트 위치에 `0`, 하단에 연속 수치와 현재 피해 배율만 표시한다.
- 커튼콜 대본은 무대 요구 심볼을 숨기고 코스트 없이 바로 상연할 수 있다. 긴 규칙 설명은 표시하지 않는다.
- 기본 연속 배율은 1회당 `+20%`, 최대 3회다. 종막의 배우는 1회당 `+40%`, 최대 `+120%`를 런타임 데이터로 교체한다.
- 커튼콜 칸이 늘어나 대본이 여러 장 돌아오면 같은 탭을 각 대본에 적용하고 한 줄 손패 안에서 나란히 배치한다.
- 다른 대본으로 전투를 끝내 연속이 끊기면 다음 전투 진입 시 연속 표식을 제거한다.
