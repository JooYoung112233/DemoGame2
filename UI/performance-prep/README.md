# 매표소·공연 준비 UI 1차 시안

`preview.png`은 감독 선택 다음 단계에서 난이도별 세이브와 시작 구성을 확인하는 1920×1080 승인본이다.

## 화면 흐름

1. 난이도별 극장과 독립 세이브를 선택한다.
2. 시작 릴과 시작 대본을 확인하거나 허용된 범위에서 변경한다.
3. 창고에서 계승 유물을 선택하고 최종 요약을 확인한다.
4. `BUY THE TICKET`으로 런을 시작한다.

## 난이도와 세이브

- 이야기, 보통, 재연을 극장 입장권 형태로 표시한다.
- 이야기 난이도를 신규 플레이어 권장값으로 표시한다.
- 난이도별 세이브가 분리되며 나중에 바꿀 수 없다는 문구를 선택 영역 바로 아래에 고정한다.
- 재연은 보통 클리어 이후 열린다. 잠금 상태는 공용 덮개와 짧은 조건만 사용한다.

## 시작 구성

- 릴은 슬롯 수와 카드별 수량이 보이는 작은 소켓으로 표시한다.
- 변경 가능한 릴 칸 수는 복원 목록 해금 데이터에 따라 버튼 문구와 상태를 바꾼다.
- 시작 대본은 작은 썸네일만 한 줄로 표시하고 전체 설명은 호버 툴팁에서 보여준다.
- 계승 유물 슬롯은 기본 수량과 복원 해금에 따른 추가 슬롯을 함께 표시한다.

## 런타임 제작 기준

- 난이도 티켓, 릴 소켓, 대본 썸네일, 유물 소켓, 요약 행, 버튼을 별도 레이어로 구성한다.
- 선택창은 전체 화면 전환 없이 작은 공용 피커 오버레이로 연다.
- 호버는 외곽선과 4~6px 이동만 사용한다.
- 매표소 배경과 카운터는 정적 이미지로 사용한다.
- 티켓 찢기, 창구 이동, NPC, 동적 조명, 파티클, 연기, 3D 회전은 사용하지 않는다.
