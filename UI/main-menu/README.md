# 타이틀 · 메인 메뉴 UI

## 현재 시안

- `preview.png`: 진행 중인 공연이 있는 메인 메뉴 1차 시안, 1920×1080.
- `preview-v2.png`: 배경 디테일을 낮추고 메뉴를 커튼의 중앙축으로 옮긴 정리 시안, 1920×1080.
- `preview-v3.png`: 거의 암전된 극장에서 중앙 커튼 틈과 메뉴만 보이는 중간 진행 상태 시안, 1920×1080.
- `understudy-title-logo-v1.png`: 확정 후보 타이틀 로고. 황동 극장 장식과 희비극 가면, 영문 `UNDERSTUDY`, 한글 부제 `대역`을 투명 배경 PNG로 분리했다.
- 거의 닫힌 커튼과 틈 사이의 미완성 무대로 제3막이 끝나지 않았다는 설정을 암시한다.
- 메인 메뉴의 커튼 열림 정도는 계정 진행도를 보여주는 장기 연출로 사용한다.

## 진행도별 커튼 프리셋

| 상태 | 커튼 연출 |
|---|---|
| 첫 실행·새 기록 | 중앙 봉합선만 희미하게 보이는 거의 완전 폐막 |
| 1막 최고 기록 | 손가락 두세 개 너비의 매우 좁은 틈 |
| 2막 최고 기록 | `preview-v3.png` 수준의 좁은 틈과 제3막 문 윤곽 |
| 첫 일반·어려움 클리어 | 무대 중앙 일부와 문 전체가 보이는 반개방 |
| 여덟 영혼 구출·주요 복원 완료 | 무대를 알아볼 수 있을 정도로 열리되 전투 화면처럼 완전히 개방하지 않음 |

- 열림 정도는 현재 진행 중인 런이 아니라 난이도 세이브의 최고 영구 진행도로 결정한다.
- 진행도가 내려가 보이지 않도록 최고 도달 상태만 저장한다.
- 정확한 구간 수는 구현 시 진행 데이터에 맞추되 최소 4단계 프리셋을 유지한다.

## 메뉴 구조

1. `CONTINUE`: 런 저장이 있을 때만 표시하며 난이도·막·층을 한 줄로 요약한다.
2. `NEW PERFORMANCE`: 난이도별 세이브 선택 및 공연 준비 화면으로 이동한다.
3. `THEATRE RECORDS`: 도감·극장 기록으로 이동한다.
4. `SETTINGS`: 설정 오버레이를 연다.
5. `EXIT`: 종료 확인 팝업을 연다.

- 런 저장이 없으면 `CONTINUE`를 숨기고 `NEW PERFORMANCE`가 첫 선택이 된다.
- 이어하기는 턴 종료 시 덮어쓴 단일 런 저장을 불러온다.
- 규칙 버전이 맞지 않는 런은 이어하기 대신 저장 버전 불일치 안내를 연다.
- 메뉴는 우측 별도 패널이 아니라 커튼 틈과 같은 중앙축에 배치한다.
- 선택 항목만 얇은 적색 천 버튼을 사용하고 나머지는 짧은 구분선을 둔 텍스트 버튼으로 처리한다.

## 구현 메모

- 기존 극장 배경, 커튼 좌·우, 무대, 관객석을 정적 레이어로 재사용한다.
- 좌·우 커튼은 같은 에셋의 위치 프리셋으로 이동하고, 상태마다 별도 완성 이미지를 만들지 않는다.
- 커튼 안쪽 배경과 객석은 어둡게 유지하며 진행도에 따라 노출을 크게 올리지 않는다.
- 커튼 틈과 타이틀 로고는 별도 레이어로 둔다. 현재는 `understudy-title-logo-v1.png`를 사용하며, 최종 교체가 필요하면 같은 비율의 후속 버전을 추가한다.
- 메뉴는 중앙 공용 버튼 프리팹 5개로 구성하고 이어하기 유무에 따라 세로 정렬만 다시 계산한다.
- 유휴 연출은 아주 작은 커튼 흔들림, 로고 밝기 변화, 선택 테두리 펄스만 사용한다.
- 배경 관객 애니메이션, 연기, 복잡한 스팟라이트는 사용하지 않는다.
