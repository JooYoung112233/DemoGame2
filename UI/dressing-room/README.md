# 분장실 UI 1차 시안

`preview.png`은 분장실 휴식 노드의 전체 화면 구조와 실제 플레이 크기를 확인하기 위한 1920×1080 승인본이다.

## 화면 구조

- 분장대와 거울을 전체 정적 배경으로 사용하고, 선택 UI는 하단 중앙의 작은 2칸 트레이로 제한한다.
- `휴식`: 최대 HP의 30%를 회복하며 현재 HP와 적용 후 HP를 함께 표시한다.
- `체력 단련`: 골드 15를 지불하고 최대 HP를 5 올리며 적용 전·후 최대치를 함께 표시한다.
- 두 행동 중 하나만 선택할 수 있으며, 이탈은 우하단의 작은 보조 버튼으로 둔다.

## 상호작용

- 호버는 얇은 금색 외곽선과 4~6px 상승만 사용한다.
- 행동 버튼을 누르면 작은 공용 확인 팝업을 띄운 뒤 결과를 즉시 적용한다.
- 현재 골드가 부족하면 체력 단련 패널 위에 공용 비활성 덮개를 표시한다.
- 회복 수치는 최대 HP를 넘지 않도록 실제 적용량과 결과 HP를 런타임에서 계산한다.

## 런타임 제작 기준

- 배경은 거울, 전구, 분장대가 포함된 정적 이미지로 사용한다.
- 전구는 배경에 굽거나 공용 발광 스프라이트 하나만 사용하며 점멸시키지 않는다.
- 두 선택 패널은 공용 베이스에 아이콘·수치·버튼을 런타임으로 올린다.
- 캐릭터 애니메이션, 거울 반사 효과, 동적 조명, 파티클, 연기, 천 시뮬레이션은 사용하지 않는다.
