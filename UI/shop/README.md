# 소품실 · 상점

## 1차 확정 시안

- `preview.png`: 1920×1080 전체 화면 검토본
- 배역 3개, 해금된 대본 3개, 유물 2개를 한 화면의 고정 진열대에 함께 보여준다.
- 잠긴 대본과 유물은 실루엣이나 잠금 슬롯으로 채우지 않고 상품 후보에서 제외한다.
- 대본 승급과 릴 제거는 우측 서비스 버튼을 누른 뒤 별도 선택창에서 처리한다.
- 현재 릴과 대본 전체는 상시 나열하지 않고 `내 극단` 버튼으로 별도 오버레이를 연다.
- 선택한 상품의 보유 수량과 구매 후 변화만 하단 정보줄에 표시한다.

## 참고한 익숙한 UI 문법

- Slay the Spire 상점처럼 서로 다른 상품 종류를 한 화면의 고정 진열대에 함께 보여주고 제거를 별도 서비스로 둔다.
- Balatro 상점처럼 보유 덱 전체를 상시 펼치지 않고 제한된 상품과 다음 행동을 우선 노출한다.
- 외형은 기존 게임의 레이아웃을 복제하지 않고 극장 소품실의 목재, 커튼, 황동 재질만 적용한다.

현재 상품 그림과 가격은 구조 확인용이다. 실제 적용에서는 프로젝트의 슬롯 심볼, 대본, 유물 에셋과 런타임 가격 데이터를 사용한다.
