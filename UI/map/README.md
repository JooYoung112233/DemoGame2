# 여정 지도

## 1차 확정 시안

- `preview.png`: 1920×1080 검토본. 하단 캐릭터·유물 HUD와 스포트라이트 광선을 제거한 안
- 한 화면에는 현재 막의 12층만 표시하고, 상단 탭으로 1·2·3막의 진행 상태를 보여준다.
- 각 층은 2~3개의 노드를 세로로 배치하며 여정은 왼쪽에서 오른쪽으로 진행한다.
- 지나온 경로는 어두운 적색, 현재 위치는 노드 자체의 발광, 다음에 선택 가능한 노드는 금색으로 구분한다.
- 숫자, 막·층, HP, 골드, 노드 상태는 런타임 UI로 처리한다.

현재 이미지는 구조 컨펌용으로 레이어를 분리하지 않는다. 지도 화면에는 감독 초상과 유물 목록을 중복 표시하지 않는다. 현재 노드 연출은 별도 조명 없이 색상·알파·크기 펄스로 구현한다.
