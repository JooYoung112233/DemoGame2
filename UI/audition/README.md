# 오디션 3택 1 UI

## 현재 시안

- `preview.png`: 오디션 전용 어둠 유물·고위험 배역 3택 1 화면, 1920×1080.
- `preview-v2.png`: 큰 모달과 카드 프레임을 제거하고 빈 무대 위의 저주받은 소품을 직접 고르는 정리 시안, 1920×1080.
- 일반 공연 보상과 달리 강한 이득과 명확한 불이득이 항상 한 쌍으로 등장한다.
- 시안의 검은 대본, 깨진 거울, 굶주린 객석은 `DESIGN.md` 17.1b에 있는 실제 초안이다.
- 어둠 유물 전체 목록은 아직 미확정이므로 이름·아이콘·이득·대가는 데이터 교체 영역으로 둔다.

## 화면 구조

- 기존 여정 화면에서 짧게 전환한 빈 오디션 무대 위에 세 개의 저주받은 소품을 직접 올린다.
- 큰 모달, 세로 카드 프레임, 진열대, 바닥 번호를 사용하지 않는다.
- 후보마다 소품 하나와 낮은 공용 이름표 하나만 표시한다.
- 이름표에는 금색 이득 아이콘과 적색 대가 아이콘을 구분선 하나로 나란히 표시한다.
- `GAIN`, `COST` 글자는 생략하되 두 효과의 글자 크기와 시각 무게는 동일하게 유지한다.
- 후보 하나를 선택한 뒤 `SIGN THE CONTRACT`로 확정한다.
- `LEAVE`는 작은 보조 버튼으로 두며 아무것도 얻거나 잃지 않고 지도에 복귀한다.

## 예시 데이터

| 이름 | 이득 | 대가 |
|---|---|---|
| 검은 대본 | 장면 피해 +50% | 망자 배역 1장 추가 |
| 깨진 거울 | 방어 2배 | 회복 불가 |
| 굶주린 객석 | 골드 2배 | 최대 HP -15 |

## 구현 메모

- 배경은 장식이 적은 정적 오디션 무대 이미지로 두며 바닥 위치 번호는 포함하지 않는다.
- 선택지는 분리된 소품 스프라이트, 낮은 이름표 하나, 아이콘 교체와 런타임 텍스트로 구성한다.
- 호버는 얇은 금색선, 선택은 4px 상승과 테두리 밝기만 사용한다.
- 시안의 소품 아래 접지광·그림자는 분위기 참고 표현이다. 실제 선택 상태는 그림자를 새로 계산하지 않고 그림자 없는 얇은 바닥 발광, 외곽선, 소품 밝기 변화만 사용한다.
- 확정 시 선택 팻말이 짧게 뒤집히거나 내려가는 공용 연출만 사용한다.
- 인물 애니메이션, 스팟라이트 빔, 연기, 파티클은 사용하지 않는다.
