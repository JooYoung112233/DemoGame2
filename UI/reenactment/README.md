# 재연 · 이력 · 퀘스트 UI

## 현재 시안

- `preview.png`: 재연 난이도 선택 메인 화면, 1920×1080.
- `preview-v2.png`: 단계별 시도 횟수를 추가하고 우측·하단 정보를 축약한 정리 시안, 1920×1080.
- 현재 재연은 자유 조절식 옵션이 아니라 1~8단계의 누적 난이도다. 단, 8은 UI의 고정 상한으로 사용하지 않는다.
- 선택한 단계에서 새로 추가되는 효과와 이전 단계의 누적 적용 여부를 분리해 보여준다.
- 일반/하드 클리어 이후 사용하는 화면이며 스토리 난이도에는 재연이 없다.

## 재연 단계

| 단계 | 명칭 | 누적되는 추가 효과 |
| --- | --- | --- |
| 1 | 베짱이가 앉았다 | 난입 확률 ×2 |
| 2 | 시계를 든 손님 | 적이 방어도 4를 가진 채 전투 시작 |
| 3 | 검열관 | 전투 시작 시 릴 역할 하나 검열 |
| 4 | 초대받지 않은 일행 | 난입자 최대 2명, 1막 보스 기믹 추가 |
| 5 | 장갑 낀 손 | 기립박수 요구치 130, 상점 가격 +15% |
| 6 | 열린 뒷문 | 난입자 종류 증가, 8턴부터 야유 |
| 7 | 모두가 대본을 읽었다 | 보스 기믹 +1, 전투 시작 시 대본 하나 봉인 |
| 8 | 마지막 손님 | 6턴부터 야유, 매 턴 HP -5 |

## 화면 구조

- 관객석의 특수 손님과 I~VIII 노드로 난이도 단계를 표현한다.
- 완료, 선택, 잠금 상태는 색상·광택·자물쇠 아이콘만으로 구현한다.
- 해금된 각 단계 노드 바로 아래에 해당 단계의 누적 시도 횟수를 작게 표시한다.
- 우측에는 선택 단계에서 새로 추가되는 효과와 이전 단계 포함 표시를 둔다.
- 최초 클리어 시 세 개 중 하나의 영구 이력을 선택한다. 이력은 난이도별 저장에 남고 최대 8개다.
- 하단에는 보유 이력과 선택 퀘스트의 요약 및 상세 화면 진입점만 둔다.
- 완료된 퀘스트는 패배해도 조각 보상을 남긴다.
- 시안의 `HISTORY 3 / 8`, `QUESTS 2 SELECTED`는 배치 검증용 예시다. 퀘스트 선택 제한과 개별 이력·퀘스트 효과는 데이터 확정 후 교체한다.

## 구현 메모

- 배경은 정적 관객석 이미지로 둔다.
- 노드는 공통 프레임에 완료/선택/잠금 스프라이트와 틴트만 바꾼다.
- 단계 노드는 하드코딩하지 않고 재연 데이터 목록으로 생성한다.
- 재연 단계가 8개를 넘으면 한 화면에는 최대 8개만 표시하고 좌우 페이지 이동 또는 수평 스크롤로 다음 구간을 연다.
- 상단의 최고 클리어 단계, 단계별 시도 횟수, 잠금 조건도 동일한 단계 데이터에서 읽는다.
- 관객은 단계마다 한 명씩 무한히 배치하지 않는다. 현재 화면 구간의 주요 손님만 최대 4명까지 보여주고 나머지는 어두운 군중 실루엣으로 합친다.
- 선택 연출은 작은 밝기 펄스와 테두리 강조만 사용한다.
- 이력 선택과 퀘스트 목록은 별도 소형 오버레이로 연다.
- 메인 화면 하단의 이력·퀘스트는 개별 슬롯이나 퀘스트 내용을 펼치지 않고 각각 한 개의 요약 버튼으로 처리한다.
- 첫 구현에서는 복잡한 조명, 연기, 관객 애니메이션을 사용하지 않는다.
