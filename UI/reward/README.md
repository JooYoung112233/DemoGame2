# 공연 보상

## 1차 확정 시안

- `preview.png`: 1920×1080 검토본. 전투 화면 위에 표시되는 중앙 모달형 보상창
- 일반 공연 종료 후 배역 3개와 대본 3개를 동시에 보여주고 여섯 개 중 하나만 선택한다.
- 위쪽은 릴 구성을 바꾸는 배역, 아래쪽은 행동 선택지를 늘리는 대본으로 구분한다.
- 배역에는 현재 보유 수량, 대본에는 현재 릴 기준 상연 확률을 런타임 텍스트로 표시한다.
- 선택 상태는 얇은 금색 외곽선, 색상 변화와 작은 Y축 이동만 사용한다.
- 보상창은 별도 전체 화면이 아니라 기존 전투 화면 위에 약 68% 폭의 모달로 표시한다.
- 배경 처리는 블러 없이 단순한 반투명 검정 오버레이만 사용한다.

현재 이미지는 구조 컨펌용이다. 배역 아이콘과 대본 표지는 최종 다듬기 단계에서 `UI/slots/symbols/`와 `UI/scripts/`의 기존 에셋으로 교체한다.
