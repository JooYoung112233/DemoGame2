# 패배·승리 정산 UI 1차 시안

`preview-victory-v2.png`과 `preview-defeat-v1.png`은 공연의 결말을 먼저 보여주고 영구 보상은 짧게 요약하는 1920×1080 결과 화면 시안이다. `preview-victory-v1.png`의 3열 정산판은 영수증처럼 보이는 문제 때문에 비교용으로만 남긴다.

## 화면 흐름

1. 승리는 열린 커튼과 떠나는 영혼, 패배는 닫히는 커튼과 멀어지는 영혼을 먼저 보여준다.
2. 결과 제목 다음에 핵심 성과와 대본 조각만 한 줄로 공개한다.
3. 계승할 유물이 있으면 작은 소켓 하나만 표시한다.
4. `VIEW PERFORMANCE`로 계산과 상세 기록을 열거나 `RETURN TO THE THEATRE`로 복귀한다.

## 대본 조각 계산

- 도달 층: 층마다 `+1`
- 처치한 보스: 보스마다 `+10`
- 완료한 무대: 무대마다 `+15`
- 해당 영혼 최초 구출: `+40`
- 시안 예시는 `36 + 30 + 15 + 40 = 121`, 기존 `63`에서 최종 `184`가 된다.
- 골드와 런 전용 자원은 다음 공연으로 넘기지 않는다.

## 승리 화면

- 중앙 무대와 구출되어 나가는 영혼이 화면의 주인공이다.
- `3막`, `첫 구출`, `+121 조각`만 큰 요약 리본으로 표시한다.
- 층·보스·무대 수는 작은 보조 행으로 내리고 발견·해금 목록은 `공연 기록 보기` 안에 둔다.
- 계승 유물은 작은 소켓을 누르면 공용 유물 피커가 열린다.

## 패배 화면

- 거의 닫힌 커튼, 멀어지는 영혼, 쓰러진 감독 자세를 우선 보여준다.
- 예시는 `8층`, `+8 조각`만 표시한다. 보스나 무대 성과가 실제로 있을 때만 같은 작은 판에 항목을 추가한다.
- `조각은 남는다`를 짧게 표시해 첫 패배에서도 다음 목표를 이해하게 한다.
- 최초 구출과 새 해금은 표시하지 않는다. 계승할 유물이 있을 때만 작은 소켓 하나를 노출한다.

## 런타임 제작 기준

- 무대, 좌우 커튼, 영혼 실루엣, 감독, 결과 제목, 하단 요약, 유물 소켓, 버튼으로 분리한다.
- 승리는 커튼 열림 상태와 영혼 페이드 아웃, 패배는 커튼 닫힘 상태와 약한 조명 페이드만 사용한다.
- 결과 요약은 `opacity + 짧은 Y 이동`으로 한 번만 등장하며 파티클은 사용하지 않는다.
- `VIEW PERFORMANCE`는 조각 계산, 발견, 해금, 전체 덱·전투 이력을 보여주는 공용 오버레이다.
- 승리와 패배는 레이아웃을 억지로 동일하게 만들지 않되 같은 무대·커튼·버튼·아이콘 에셋을 공유한다.
