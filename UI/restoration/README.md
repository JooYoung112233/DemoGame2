# 복원 목록 UI 1차 시안

`preview-v4.png`은 극장 안에 놓인 실제 물품을 눌러 기능을 한 번씩 복원하는 1920×1080 영구 해금 화면이다. 해금한 기능은 해당 난이도 세이브의 이후 모든 공연에 적용된다. 개별 전투 대본을 강화하는 화면이 아니다. 이전 프리뷰는 표현 비교용으로만 남긴다.

## 화면 구조

- 상단에는 뒤로 가기, 화면 제목, 보유 대본 조각, `복원 수 / 9`를 고정한다.
- 기존 극장 배경 안에 전체 9개 기능 물품을 실제 위치에 배치한다. 스크롤, 캐릭터 이동, 확대·축소는 사용하지 않는다.
- 물품에는 작은 핫스팟과 비용만 표시하며 이름과 효과는 선택했을 때 작은 공용 팻말에 표시한다.
- 선택 팻말에는 기능 해금 전후 그림, 비용, 복원 후 잔액, 선행 조건만 표시한다.
- 복원 버튼을 누르면 공용 확인 팝업 없이 버튼 위치에서 바로 확정한다. 영구 구매이므로 버튼을 짧게 길게 누르는 홀드 방식도 후보로 둔다.

## 실제 복원 항목

| 분류 | 항목 | 조각 | 효과 | 선행 |
|---|---|---:|---|---|
| 무대 | 연습실 | 100 | 시작 릴 1칸 변경 | 없음 |
| 무대 | 전속 배우 | 220 | 시작 릴을 3칸까지 변경 | 연습실 |
| 무대 | 넓어진 무대 | 120 | 슬롯 3칸 → 4칸 | 없음 |
| 대본 | 초고 | 140 | 시작 대본 +1 | 없음 |
| 대본 | 개정판 | 260 | 시작 대본 +1, 누적 2 | 초고 |
| 대본 | 남은 페이지 | 130 | 무대 조건을 처음부터 표시 | 없음 |
| 무대 뒤 | 분장대 | 160 | 소품 슬롯 +1 | 없음 |
| 무대 뒤 | 극장 창고 | 180 | 계승 유물 슬롯 +1 | 없음 |
| 무대 뒤 | 깊은 창고 | 320 | 계승 유물 슬롯 +1, 누적 2 | 극장 창고 |

## 노드 상태

- `복원 완료`: 수리된 물품, 따뜻한 국부 조명, 작은 체크 메달.
- `복원 가능`: 파손됐지만 형태가 보이는 물품과 작은 금색 핫스팟.
- `선택`: 물품 주위의 금색 원형 링과 선택 팻말로 향하는 얇은 포인터. 파티클은 사용하지 않는다.
- `조각 부족`: 물품은 보이되 비용만 붉게 표시하며 버튼을 비활성화한다.
- `선행 잠금`: 물품에 실제 천·판자·사슬·자물쇠 덮개를 씌운다.
- 선택 팻말에는 `영구·이후 모든 공연 적용`을 고정한다.

## 런타임 제작 기준

- 극장 배경, 물품 9종의 파손·복원 상태, 잠금 덮개, 국부 조명, 핫스팟, 비용표, 연결선, 공용 선택 팻말, 버튼으로 분리한다.
- 연결선은 `연습실 → 전속 배우`, `초고 → 개정판`, `극장 창고 → 깊은 창고` 세 개만 사용한다.
- 상태 변화는 색상·외곽선·체크·자물쇠만 교체한다.
- 복원 완료 연출은 물품 덮개 제거, 복원 스프라이트 교체, 국부 조명 켜짐, 1.0→1.05→1.0 스케일로 끝낸다.
- 카메라 이동, 캐릭터 이동, 실시간 건물 변형, 파티클, 3D 방 전환은 사용하지 않는다.

## 물품 대응

- 연습실: 감독 의자와 클래퍼
- 전속 배우: 가면걸이·배역 게시판
- 넓어진 무대: 무대 확장 윈치와 레버
- 초고: 서고 책상 위 원본 대본
- 개정판: 사슬로 묶인 두꺼운 대본
- 남은 페이지: 벽에 붙은 찢어진 페이지와 확대경
- 분장대: 깨진 분장 거울과 소품 서랍
- 극장 창고: 계승 물품 상자
- 깊은 창고: 판자로 닫힌 창고문
