# 공용 오버레이 UI

폴더를 세분화하지 않고 여러 화면에서 재사용하는 선택·상세 오버레이를 이 폴더에 함께 둔다.

## 현재 시안

- `preview-picker-script.png`: 공연 준비 화면에서 시작 대본을 교체하는 상황을 적용한 공용 선택창 대표 시안, 1920×1080.

## 공용 선택창 구조

- 균일한 검정 딤 위에 약 `1040×620px` 중앙 패널을 연다.
- 제목, 목록 슬롯, 선택 상세, 변경 전·후 한 줄, 취소·확정 버튼만 사용한다.
- 대본, 릴, 유물, 캐릭터, 각색 대상, 상점 서비스 대상, 사건 대상을 같은 셸에서 교체한다.
- 대상별로 새 패널을 그리지 않고 목록 슬롯 프리팹과 런타임 아이콘·텍스트만 바꾼다.
- 배경 블러, 페이지 넘김, 스포트라이트, 파티클, 3D 회전은 사용하지 않는다.
