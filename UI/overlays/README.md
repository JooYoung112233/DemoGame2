# 공용 오버레이 UI

폴더를 세분화하지 않고 여러 화면에서 재사용하는 선택·상세 오버레이를 이 폴더에 함께 둔다.

## 현재 시안

- `preview-picker-script.png`: 공연 준비 화면에서 시작 대본을 교체하는 상황을 적용한 공용 선택창 대표 시안, 1920×1080.
- `preview-details-performance-v3.png`: 확대된 글자·행 대비·숫자 정렬을 유지하면서 공용 선택창의 암목재·버건디·얇은 황동 프레임과 공연 이력의 색감으로 통일한 공용 상세창 기준안, 1920×1080.
- `preview-state-availability.png`: 같은 물품을 사용 가능·잠김·현재 비활성·재화 부족으로 비교한 공용 상태 기준 시트, 1920×1080.

## 공용 선택창 구조

- 균일한 검정 딤 위에 약 `1040×620px` 중앙 패널을 연다.
- 제목, 목록 슬롯, 선택 상세, 변경 전·후 한 줄, 취소·확정 버튼만 사용한다.
- 대본, 릴, 유물, 캐릭터, 각색 대상, 상점 서비스 대상, 사건 대상을 같은 셸에서 교체한다.
- 대상별로 새 패널을 그리지 않고 목록 슬롯 프리팹과 런타임 아이콘·텍스트만 바꾼다.
- 배경 블러, 페이지 넘김, 스포트라이트, 파티클, 3D 회전은 사용하지 않는다.

## 공용 상세창 구조

- 균일한 검정 딤 위에 약 `1000×650px` 중앙 패널을 연다.
- 제목, 상태, 최대 3개 탭, 두 열의 짧은 데이터 행, 작은 요약 스트립과 닫기 버튼만 사용한다.
- 공연 기록은 `SUMMARY / COMPANY / DISCOVERIES`, 재연 기록과 퀘스트는 같은 위치의 탭 이름과 행 데이터만 교체한다.
- 긴 목록과 전투 로그를 한 탭에 함께 펼치지 않는다.

## 공용 사용 가능 상태

- `사용 가능`: 원래 색과 정보, 버건디 행동 버튼, 얇은 황동 포커스 테두리를 사용한다.
- `잠김`: 내용 대신 천 덮개·사슬·자물쇠와 해금 조건만 표시한다. 가격과 행동 버튼은 숨긴다.
- `비활성`: 내용은 식별 가능하게 유지하고 전체 명도·채도를 낮춘다. 자물쇠 없이 비활성 버튼과 현재 사용할 수 없는 이유 한 줄을 표시한다.
- `재화 부족`: 물품은 정상 명도로 유지하고 보유량과 필요 가격을 함께 표시한다. 부족한 가격만 흐린 적색으로 바꾸고 행동 버튼을 비활성화한다.
- 색만으로 상태를 구분하지 않는다. 잠금은 덮개·자물쇠, 비활성은 노출된 내용·꺼진 버튼, 부족은 보유량 비교로 중복 표현한다.
- 호버·포커스는 사용 가능한 상태에만 금색 외곽선을 표시한다. 잠김·비활성 상태에서는 클릭 소리와 눌림 애니메이션을 재생하지 않는다.
