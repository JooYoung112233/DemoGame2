# 감독 선택 UI 1차 시안

`preview.png`은 런 시작 전 감독 선택 화면의 구조와 실제 플레이 크기를 확인하기 위한 1920×1080 승인본이다.

## 캐릭터 에셋

- 캐릭터 원본과 순서는 `UI/character/character-lineup-v2.png` 및 `UI/character/README.md`를 기준으로 한다.
- 연출가, 거울의 배우, 악장, 광란의 감독, 어릿광대, 타락한 감독, 관객의 총아, 종막의 배우 순서다.
- 최종 런타임에서는 생성 시안에 포함된 캐릭터 이미지를 잘라 쓰지 않고 기존 캐릭터 원본을 그대로 배치한다.

## 화면 구조

- 왼쪽에는 현재 선택한 감독 한 명을 큰 크기로 표시한다.
- 하단에는 감독 8명의 작은 썸네일을 한 줄로 배치하고 선택·잠금 상태를 표시한다.
- 오른쪽에는 이름, 플레이 성향, 고유 능력, 유품, 최대 HP·코스트, 선택 버튼을 표시한다.
- 긴 배경 이야기와 시작 릴·대본 목록은 이 화면에 펼치지 않는다.

## 잠금 상태

- 기본 해금 감독은 원본 캐릭터를 그대로 표시한다.
- 잠긴 감독은 실루엣이 희미하게 보이는 공용 극장식 셔터와 작은 잠금 아이콘을 올린다.
- 잠금 감독에 호버하면 하단 한 줄 영역에 해금 조건이나 진행도를 표시한다.

## 런타임 제작 기준

- 큰 캐릭터, 8개 썸네일, 정보 패널, 능력·유품 아이콘, 잠금 덮개, 버튼을 별도 레이어로 구성한다.
- 호버는 얇은 외곽선과 4~6px 위치 이동만 사용한다.
- 캐릭터 회전, idle 애니메이션, 움직이는 스포트라이트, 커튼 애니메이션, 파티클, 동적 조명은 사용하지 않는다.
- 실제 능력 수치와 해금 상태는 저장 데이터에서 바인딩한다.
