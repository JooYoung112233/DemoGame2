# 극장 뎁스 레이어

모든 파일은 동일한 `1672x941` 캔버스와 좌표계를 사용한다. 엔진에서는 화면 크기에 맞춰 네 레이어를 함께 스케일한다.

## 합성 순서

1. `stage.png` — 불투명한 빈 무대와 교체 가능한 후면 배경
2. `curtain-valance.png`, `curtain-left-open.png`, `curtain-right-open.png` — 열린 커튼
3. `audience.png` — 좌우 발코니와 하단 관객석
4. `director-back.png` — 감독석 뒤의 연속된 객석 난간
5. `director-front.png` — 하단 작업대와 대본 배치 면
6. 캐릭터 — 화면 맨 왼쪽 하단, 작업대보다 앞
7. 슬롯, 대본 손패와 HUD

`preview.png`는 네 파일의 좌표와 가림 관계를 확인하기 위한 검수 합성본이며 런타임 에셋이 아니다.

## 다른 런타임 요소

- 적과 무대 연출은 `stage`보다 앞, `curtain`보다 뒤에 둔다.
- 캐릭터는 감독석 내부나 무대 가장자리가 아니라 화면 맨 왼쪽 하단의 객석 전경에 둔다.
- 기준 캔버스에서 캐릭터 권장 영역은 대략 `x=-20..380`, `y=520..920`이며 작업대보다 앞에 렌더링한다.
- 슬롯, 대본 손패와 HUD도 `director-front`보다 앞에 둔다.
- 관객석 하단 대부분은 전투 중 감독 작업대에 가려지며, 환호 연출이나 작업대 이동 시 드러낼 수 있다.
- 무대 변경은 `stage`의 후면 배경만 교체하고, 커튼 닫힘 → 배경 교체 → 커튼 열림 순서로 연출한다.

## 커튼 전환

### 파일

- 고정 상단: `curtain-valance.png`
- 열린 상태: `curtain-left-open.png`, `curtain-right-open.png`
- 닫힌 상태: `curtain-left-closed.png`, `curtain-right-closed.png`
- 완전 가림 검수/안전 덮개: `curtain-closed.png`

### 닫기 → 배경 교체 → 열기

1. **0.00~0.55초 — 닫기:** 좌우 바깥쪽에서 중앙으로 진행하는 사각 마스크로 `closed` 패널을 드러낸다. 동시에 `open` 패널은 중앙 방향으로 캔버스 폭의 3~4%만 이동하고 알파를 1→0으로 낮춘다.
2. **0.55~0.70초 — 맞물림:** 중앙선에서 좌우 패널을 각각 3px 정도 눌렀다가 되돌려 천의 무게감을 준다.
3. **0.70초 — 무대 교체:** 커튼이 완전히 닫힌 프레임에서 `stage` 후면 배경을 교체한다.
4. **0.70~0.85초 — 정지:** 새 무대의 조명과 음향을 먼저 준비한다.
5. **0.85~1.45초 — 열기:** 위 과정을 역순으로 실행하고 마지막 0.15초에 새 무대 조명을 올린다.

- 위치 보간은 `easeInOutCubic`, 알파는 `smoothstep`을 권장한다.
- 열린 커튼 이미지를 가로로 크게 늘리지 않는다. 묶인 천이 고무처럼 늘어나는 현상을 피하기 위해 열린/닫힌 패널 사이를 마스크와 짧은 이동으로 전환한다.
- 전환 중 적, 피해 숫자와 선택 입력은 숨기거나 잠근다. 커튼이 완전히 닫힌 순간에만 무대 데이터를 바꾼다.
