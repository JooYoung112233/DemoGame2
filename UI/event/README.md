# 사건·즉흥극 UI 1차 시안

`preview.png`은 사건 노드의 전체 화면 구조와 실제 플레이 크기를 확인하기 위한 1920×1080 승인본이다.

## 화면 구조

- 왼쪽에는 사건명, 정적인 사건 삽화, 2~3줄의 짧은 이야기를 배치한다.
- 오른쪽에는 1~3개의 주요 선택지를 세로로 배치한다.
- 각 선택지는 행동 이름과 `대가 → 결과`를 큰 아이콘과 숫자로 직접 표시한다.
- 아무것도 잃거나 얻지 않는 이탈은 큰 선택지 카드로 만들지 않고 우하단의 작은 보조 버튼으로 고정한다.

## 상호작용

- 호버: 얇은 금색 외곽선과 4~6px 수평 이동만 사용한다.
- 선택: 선택지를 한 번 눌러 고정하고 하단 `ACCEPT` 버튼을 활성화한다.
- 확정: 즉시 적용 가능한 수치는 바로 반영한다. 대본이나 배역처럼 대상을 골라야 하면 선택지 아래에 5칸짜리 소형 보유 목록 스트립을 펼친다.
- 결과가 무작위인 사건만 확률 또는 무작위 표기를 사용하며, 확정 결과의 대가를 숨기지 않는다.

## 런타임 제작 기준

- 사건 삽화, 사건 텍스트, 선택지 목록을 서로 교체 가능한 데이터 영역으로 분리한다.
- 선택지 배경은 공용 정적 스프라이트를 사용하고 아이콘·수치·문구는 런타임 UI로 올린다.
- 배경은 단순 검정 오버레이만 사용하며 블러, 동적 조명, 연기, 파티클, 캐릭터 애니메이션은 사용하지 않는다.
- 보유 목록 스트립은 작은 썸네일·코스트 표식·선택 외곽선만 사용하며 전체 손패나 긴 설명을 보여주지 않는다.
- 선택 결과의 긴 설명은 툴팁에서만 보여준다.
