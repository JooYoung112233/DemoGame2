# 이야기 장면 UI

## 현재 시안

- `preview.png`: 새 공연 시작 전의 매표소 프롤로그 장면, 1920×1080.
- 빈 매표소, 어둠 속에서 표를 건네는 손과 하단의 짧은 대사판만 사용한다.
- 공연 준비 화면이나 사건 선택 화면과 달리 선택지 없이 문장을 순서대로 넘기는 서사 화면이다.

## 공용 화면 구조

- 배경 장면이 화면 대부분을 차지한다.
- 좌상단에는 장면 구분을 위한 작은 장·절 제목만 표시한다.
- 하단 대사판은 약 `900×155px`이며 화자 이름과 최대 두 줄의 문장만 표시한다.
- 대사판 우하단의 작은 진행 표식으로 클릭·확인키 입력을 알린다.
- 인물 초상화, 대화 선택지, 전투 HUD와 상태 수치는 표시하지 않는다.

## 주요 이야기 프리셋

| 장면 | 정적 배경·교체 요소 |
|---|---|
| 매표소 도입 | 폐쇄된 극장 입구, 매표소, 표를 내미는 손 |
| 감독의 자리 | 빈 무대, 객석 전경, 감독 의자와 놓인 대본 |
| 영혼 구출 | 열린 커튼, 주연 실루엣이 객석 쪽으로 내려오는 장면 |
| 초대 감독 | 3막 무대, 오래된 감독 실루엣과 비어 있는 지휘 자리 |
| 마지막 장면 | 구출된 여덟 실루엣이 객석에 앉고 감독 자리가 무대 위를 향함 |
| 엔딩 | 완전히 열린 극장문과 꺼진 매표소 |

## 상호작용

- 화면 클릭, 확인키 또는 게임패드 확인으로 다음 문장·프레임을 연다.
- `ESC`는 일시정지 메뉴를 열며 이야기 자체를 건너뛰지 않는다.
- 이야기 건너뛰기는 일시정지 메뉴의 작은 `SKIP SCENE` 항목으로 제공하고 확인 팝업을 한 번 연다.
- 선택이 필요한 서사는 이야기 장면에 버튼을 추가하지 않고 기존 `사건·즉흥극` 화면으로 넘긴다.

## 구현 메모

- 정적 배경, 교체 가능한 인물·손 실루엣, 장 제목, 화자 탭, 대사판, 진행 표식으로 분리한다.
- 대사는 이미지에 굽지 않고 로컬라이즈 가능한 런타임 텍스트로 표시한다.
- 장면 전환은 짧은 검정 페이드와 오브젝트 알파만 사용한다.
- 립싱크, 캐릭터 전신 애니메이션, 카메라 이동, 파티클, 동적 스포트라이트는 사용하지 않는다.
