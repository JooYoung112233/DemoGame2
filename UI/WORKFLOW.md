# UI 제작 및 확인 절차

모든 UI 에셋은 아래 순서로 제작한다.

1. **전체 시안 제작**: 실제 게임 화면의 크기와 주변 UI를 고려한 합성 이미지부터 만든다.
2. **이미지 컨펌**: 형태, 비율, 색, 정보 위계와 게임 내 가독성을 확인한다. 이 단계에서는 개별 에셋으로 자르지 않는다.
3. **시안 수정**: 피드백을 반영해 전체 이미지가 확정될 때까지 반복한다.
4. **레이어 설계**: 고정 바탕, 가변 수치, 아이콘, 게이지, 상태 오버레이와 애니메이션 요소를 구분한다.
5. **런타임 에셋 분리**: 확정된 시안만 투명 PNG 등 실제 사용 단위로 분리한다.
6. **합성 검수**: 분리한 에셋을 다시 조립해 확정 시안과 크기·정렬·가독성이 같은지 확인한다.
7. **확인 후 저장**: 사용자가 `확인`하면 해당 UI 작업만 커밋하고 푸시한다.

## 제작 원칙

- 숫자, 제목, 설명처럼 변경되는 정보는 이미지에 굽지 않고 런타임 텍스트로 둔다.
- 증가·감소하거나 최대치가 변하는 자원은 고정 칸 수 이미지로 만들지 않는다.
- 실제 1920×1080 화면에서 자주 보는 정보의 우선순위와 최소 표시 크기를 먼저 검증한다.
- 생성 원본, 검수용 전체 시안, 런타임 분리 에셋을 서로 다른 폴더에 보관한다.
- 확정 전 시안은 `concepts/` 또는 `previews/`에 두며 런타임 폴더에 넣지 않는다.
