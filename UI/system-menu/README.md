# 일시정지·설정·확인 팝업 UI

## 현재 시안

- `preview.png`: 전투 중 여는 일시정지 메뉴 1차 시안, 1920×1080.
- `preview-settings-audio.png`: 같은 공용 패널 셸을 사용하는 설정의 `AUDIO` 탭 대표 시안, 1920×1080.
- `preview-confirm-abandon.png`: 공연 포기 문구를 적용한 공용 2버튼 확인창 대표 시안, 1920×1080.
- 전투 화면 위에 균일한 검정 오버레이만 씌우며 배경 블러는 사용하지 않는다.
- 중앙 패널은 약 `470×530px`이며 전투 맥락을 충분히 남긴다.

## 일시정지 메뉴

1. `RESUME`: 현재 화면으로 복귀한다.
2. `SETTINGS`: 같은 크기의 설정 패널로 내용만 교체한다.
3. `RETURN TO TITLE`: 현재 런을 유지하고 메인 메뉴로 이동한다.
4. `ABANDON PERFORMANCE`: 공연 포기 확인 팝업을 연다. 즉시 실행하지 않는다.

- 진행 상황은 턴 종료 시 저장되므로 안내 문구를 하단 한 줄로 고정한다.
- `ESC`는 항상 한 단계 닫기이며 일시정지 루트에서는 전투로 복귀한다.

## 설정 패널 규칙

- 탭은 `AUDIO`, `VIDEO`, `CONTROLS`, `ACCESSIBILITY` 네 개만 사용한다.
- 한 번에 선택 탭의 항목만 표시하며 긴 한 화면 스크롤은 사용하지 않는다.
- 오디오: 전체·음악·효과·관객 음량.
- 비디오: 화면 모드·해상도·수직 동기화·UI 스케일.
- 조작: 키보드/게임패드 바인딩과 진동.
- 접근성: 화면 흔들림·번쩍임·텍스트 크기·색상 구분 보조.
- 적용은 즉시 반영하며 `RESET TO DEFAULTS`만 확인 팝업을 연다.

## 공용 확인 팝업

- 제목, 최대 두 줄 설명, 취소와 확정 두 버튼만 사용한다.
- 취소가 기본 선택이며 위험 확정만 흐린 적색으로 표시한다.
- 공연 포기, 초기화, 저장 버전 불일치와 복구 불가 안내에 같은 프레임을 재사용한다.
- 저장 버전 불일치는 취소 버튼 없이 `START NEW PERFORMANCE` 하나만 표시할 수 있다.

## 구현 메모

- 균일 검정 오버레이, 공용 중앙 패널, 메뉴 행, 탭, 슬라이더·토글, 2버튼 확인창으로 분리한다.
- 배경 블러, 동적 조명, 커튼 애니메이션, 파티클과 큰 그림자는 사용하지 않는다.
- 키보드·게임패드 포커스는 얇은 금색 인셋 테두리 하나로 통일한다.
